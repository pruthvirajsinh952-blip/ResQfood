# ResQfood – Food Rescue Management System

ResQfood is a web-based food rescue platform designed to reduce food waste by connecting food donors with people and communities who need food.

## Features
- User registration and login
- Food donation system
- Available food listings
- Food claiming functionality
- User dashboard
- Google Maps integration for pickup locations
- About Us and Contact pages
- Responsive design

## Technologies Used
- HTML5
- CSS3
- JavaScript
- PHP
- MySQL
- XAMPP
- Google Maps
